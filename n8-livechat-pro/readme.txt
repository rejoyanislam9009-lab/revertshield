Contributors: n8

Advanced live chat and support inbox with agents, attachments, typing indicators, tags, SLA automation, CSAT, analytics, audit export and signed webhooks.

== Installation ==
1. Upload the n8-livechat-pro folder or ZIP through WordPress Plugins.
2. Activate N8 LiveChat Pro.
3. Configure N8 LiveChat -> Settings and Automation.
4. Use N8 LiveChat -> Inbox to answer visitors.
